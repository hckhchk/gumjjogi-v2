# gumjjogi-v2

금쪽이 33기 자성 가르치기 — **친구 금쪽이와 비교하기** 기능을 더한 버전입니다.
기존 버전: https://github.com/hckhchk/gumjjogi

## 바뀐 점
- 🤝 친구 금쪽이와 비교하기: 친구를 골라 두 금쪽이의 노트(장면 지도)와 12문제 예상 결과를 나란히 비교하고, 결과가 다른 문제를 바탕으로 토론 질문을 보여 줍니다. 알게 된 점은 한 줄 메모로 남길 수 있습니다(관리자 대화 로그에 기록).
- 기록 분리: Firestore 컬렉션 `gumjjogi_v2`, `gumjjogi_v2_chat`을 사용해 기존 버전(`gumjjogi`)과 기록이 섞이지 않습니다.
